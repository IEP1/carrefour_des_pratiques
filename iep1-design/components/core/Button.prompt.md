Flat, sharp-cornered button for institutional communications (decks, letters, simple web forms) — use when a document needs a clickable call to action.

```jsx
<Button variant="primary" size="md" onClick={() => {}}>Voir la circulaire</Button>
```

Variants: `primary` (deep blue, default), `navy` (dark, for use on light backgrounds needing more contrast), `outline` (transparent with blue border, for secondary actions), `ghost` (text-only, for tertiary/inline actions). Sizes: `sm`, `md`, `lg`. Hover darkens 8%; press scales to 0.98 — matches brand's conservative, non-bouncy motion stance.
